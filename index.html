Invoice Manager

Receipt scanning and spending tracker

Upload a receipt photo or PDF and a Java (Spring Boot) backend reads it with Google Vision OCR, then GPT-4o mini turns the text into structured items, tax and totals. Items are categorized by keyword rules first, with GPT as the fallback, and the backend flags duplicate charges, expensive items and unusually high totals. The React frontend keeps a receipt history with search, filters, category summaries and CSV/PDF export.

  • React
  • TypeScript
  • Java (Spring Boot)
  • Google Vision OCR
  • OpenAI GPT-4o mini
