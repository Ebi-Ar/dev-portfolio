# Developer Portfolio

Personal developer portfolio for Ebrahim Arefi — hand-written HTML/CSS with GSAP
animation, embedding three live demo apps in-page.

**Live:** https://ebi-ar.github.io/dev-portfolio/

## Structure

- `index.html` — the entire portfolio page (markup, styles, and scripts inline)
- `apps/invoice/` — Invoice Manager, built demo
- `apps/gymm/` — Gym tracking app, built demo
- `apps/food/` — Diaspora Food Analyzer, built demo

The `apps/` folders hold production builds of separate projects; they are served
as static files and loaded into the page through iframes.
